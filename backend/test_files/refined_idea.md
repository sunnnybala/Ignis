# Refined Research Idea

## Title
Sentiment Analysis on Movie Reviews using Logistic Regression

## Objective
Build a baseline sentiment classifier for the IMDB movie reviews dataset to establish benchmark performance using simple machine learning techniques.

## Methodology
- Use TF-IDF vectorization for text feature extraction
- Train a Logistic Regression classifier
- Evaluate on test set with accuracy, precision, recall, and F1-score
- Generate a confusion matrix visualization

## Expected Outcome
Achieve >80% test accuracy as a baseline for sentiment classification.

## Dataset
IMDB movie reviews dataset with binary sentiment labels (positive/negative).

## Technical Requirements
- Python with scikit-learn for ML
- pandas for data manipulation
- matplotlib for visualization
